Catino

A crash game where the crash is a cat getting distracted.

Up to 60 people join from their phones by scanning a QR code and bet on the same cat. Four seasons each change one rule, and the forecast shows the next three in advance.

What it proves

  • Provable fairness. The server publishes a SHA-256 seal of its secret before anyone can cash out. Every player's device adds a random seed, and the crash point is the server value XOR a hash of all seeds, so neither side can steer it.
  • Server is the source of truth. Payouts use exact decimals; the client only displays.
  • Honest odds. Season bonuses default to +4%, which keeps every strategy under 100% return.

Unity 6 · C# · Python server (a friend's repo; I built the client against it) · SHA-256 · MIT licence

Verifiable

Proof: press Q in the game to open Schrödinger's Box and see the seal, seeds and math checked.

Line Ready

A kitchen training simulation, built from the line.

A cook gets a ticket, follows a recipe spec, portions ingredients on a scale and handles an allergen constraint. A deterministic grader turns the action log into feedback that explains itself. The restaurant and menu are fictional.

What it proves

  • Rules separate from the engine. The domain and grader are plain C# with their own tests, outside Unity.
  • Replayable. Player actions are recorded as a log and the plate is rebuilt from it, which is what makes grading explainable.
  • End to end, planned. Interaction → rules → event → database → SQL metrics → dashboard.

Unity 6 · C# · backend and SQL dashboard next · a training prototype, not validated training software

In progress

Done: scale spike, scoring, action log. Next: grader feedback, backend, dashboard.
